## 怎么换成别的收款码

**① 手机上保存收款码**

- 微信：`我` → `服务` → `收付款` → `二维码收款` → 右上角 `保存收款码`
- 支付宝：首页 `收付款` → `扫码收款` → 保存收款码

**② 传到电脑**

微信 → 文件传输助手；或者 QQ → 我的设备。存下来后会是一张 png/jpg。

**③ 改名成 `qr.jpg`，放到这个目录**

```
<仓库根目录>\donate\qr.jpg
```

> 建议先压缩到 200 KB 以内（微信里的"编辑→裁掉白边"就够了）。
> PNG 比 JPG 清楚，二维码别缩放得太狠，不然扫不出来。

**④ 让 README 显示它**

仓库根目录 `README.md` 里那段打赏文字，换成下面这一段（图片居中，下面一行小字）：

```markdown
<p align="center">
  <img src="donate/qr.jpg" width="220" alt="打赏二维码">
  <br>
  <sub>谢谢给的 token</sub>
</p>
```
