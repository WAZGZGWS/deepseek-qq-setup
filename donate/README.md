## 如果你想放自己的收款码

1. 把二维码图片命名为 `qr.png` 放进这个目录
2. 在仓库根目录的 `README.md` 里把链接指向它（已经有 `donate/` 的链接，把文字换成图片即可）：

```markdown
<img src="donate/qr.png" width="200" alt="打赏二维码">
```
