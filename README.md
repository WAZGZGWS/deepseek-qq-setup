## 为什么这套能“像真人”

桥接不是简单的“收到→问模型→发回”，它内置了：

- **二代仿真（reserved2）**：AI 自己决定看消息、发言、等待、潜水；`qq_wait_for_messages` 长轮询 5 分钟
- **分段发送 + 打字间隔**：1~3 秒一条、随机长停顿、连续刷屏上限 8 条
- **人格卡**（`roles/*.md`）+ **角色扮演**注入，群友改不了
- **黑话学习**：从群里提取词条、主动查含义
- **分层人物记忆 + 入群感知**：记得“这个人我在别的群见过”
- **主动开口 / 定时任务 / 定时静默**

## QQ 空间“随机发动态，内容它自己想”

已经写了一个本地 MCP server：`dsh-qq\qq-bridge-enhanced-v1.1.0\src\mcp-qzone.mjs`

- 工具：`qzone_publish`（文字 / 最多 9 张图 / 可见范围）、`qzone_delete`（按 tid 删）
- 走 NapCat 扩展接口 `send_qzone_msg` → HTTP `127.0.0.1:3000`
- **自带护栏**：每天最多 3 条、两条至少隔 90 分钟（`QZONE_DAILY_CAP` / `QZONE_MIN_GAP_MS` 可调）
- 已注册进 desktop profile 的 `cordis.patch.yml`（`mcp-qzone` → `@deepseek-ai/dsh-mcp-client`）
- 已在当前 DSH 里挂上（工具名 `mcp__qzone__qzone_publish`），刚才实测调用返回 `fetch failed`——因为 NapCat 还没起，属于预期
- 已在 `plugins/qq-agent-presets/qq-tool-restrict.mjs` 的 `SAFE_PREFIXES` 里加了 `mcp__qzone__`，否则 QQ 会话的白名单会把它拦掉

### 怎么让它“随机、自己想内容”

等桥接跑起来、机器人在线后，用**你的大号私聊小号**发这一条：

```
/remind add random 2 10:00-23:30 ai 现在是自由时间。想发 QQ 空间就用 qzone_publish 发一条，内容你自己定，别像广告；不想发就回 SKIP。
```

- `random 2` = 每天随机 2 次（建议 1~3，别超过 3）
- `10:00-23:30` = 允许发的时间段
- `ai ...` = 到点唤醒 AI，让它自己决定发不发、发什么
- 想改口味就改那句提示；想固定每天一条就换成 `daily 21:00 ai ...`

> 空间接口比发消息更容易触发风控。一天 1~2 条、别带链接/二维码，小号才活得久。

## 风险与边界（必须知道）

- ⚠️ **协议端 = 非官方登录**。用**小号**承担风险，别用主号；QQ 官方随时可能封此类登录方式。
- ⚠️ 默认白名单为空 → 谁都不理；填了白名单才响应，`ownerQQ` 只用于管理通道。
- ⚠️ 桥接能通过 MCP 让模型发消息，权限分级 L0~L3，L3 需 TOTP；建议先只用 L1。
- 单实例锁：桥接只能跑一个。
